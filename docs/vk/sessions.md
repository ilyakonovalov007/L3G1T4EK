    <p style="font-size: 1.15rem; line-height: 1.6; margin: 0;"><strong>Двухфакторная аутентификация (2FA)</strong> — это ваш главный щит. Благодаря ей, даже если мошенники узнают ваш пароль, они не смогут войти в аккаунт без доступа к вашей почте или телефону (SMS-кода).</p>
  </div>

  <h2 style="margin-top: 30px; font-size: 1.6rem; font-weight: 700; color: var(--vp-c-text-1);">🔒 Почему важно включить двойную защиту и проверять список устройств?</h2>
  <br>
  <p style="font-size: 1.1rem; line-height: 1.6; color: var(--vp-c-text-1); margin-bottom: 15px;">
    Большинство людей думают: <em>«Я придумал сложный пароль из букв и цифр, меня никто не взломает»</em>. К сожалению, сегодня этого уже недостаточно. Пароли крадутся незаметно — через поддельные ссылки в интернете или вирусы на компьютере.
  </p>

  <p style="font-size: 1.1rem; line-height: 1.6; color: var(--vp-c-text-1); margin-bottom: 25px;">
    Если злоумышленник узнает ваш пароль, у него уйдет совсем немного времени, чтобы войти в ваш профиль. Чтобы этого не случилось, в настройках есть два главных инструмента:
  </p>

  <ul style="list-style: none; padding: 0; font-size: 1.05rem; line-height: 1.6; margin-bottom: 35px;">
    <li style="margin-bottom: 15px; display: flex; gap: 12px; align-items: flex-start;">
      <span style="font-size: 1.3rem; line-height: 1;">🛡️</span>
      <span><strong>Двойная защита (подтверждение по телефону)</strong> — это ваш главный цифровой замок. Она добавляет второй рубеж безопасности. Даже если мошенник знает ваш логин и пароль, он <strong>не сможет войти в аккаунт</strong>. Система просто не пустит его без специального одноразового кода, который приходит только на ваш личный мобильный телефон.</span>
    </li>
    <li style="margin-bottom: 15px; display: flex; gap: 12px; align-items: flex-start;">
      <span style="font-size: 1.3rem; line-height: 1;">📱</span>
      <span><strong>Список подключенных устройств</strong> — это специальный раздел в настройках, который показывает все телефоны, компьютеры и планшеты, с которых прямо сейчас открыта ваша страница. Он позволяет вовремя заметить постороннюю активность и моментально завершить чужие сеансы, закрыв доступ к профилю.</span>
    </li>
  </ul>

  <h2 style="margin-top: 40px; font-size: 1.6rem; font-weight: 700; color: var(--vp-c-text-1);">⚠️ Как выглядит угроза в реальной жизни?</h2>
  <br>
  <p style="font-size: 1.1rem; line-height: 1.6; color: var(--vp-c-text-1); margin-bottom: 25px;">
    Мошенникам нужен доступ к вашей странице не ради любопытства — на этом строятся опасные схемы обмана. Вот как разворачиваются две самые частые ситуации, если защита не настроена:
  </p>

  <div style="background: var(--vp-c-bg-alt); padding: 20px; border-radius: 12px; margin-bottom: 20px; border: 1px solid var(--vp-c-divider);">
    <h3 style="margin-top: 0; margin-bottom: 10px; font-size: 1.3rem; font-weight: 700; color: var(--vp-c-text-1);">🕵️‍♂️ Ситуация 1: Тайный гость и сбор личной информации</h3>
    <p style="margin-bottom: 10px; font-size: 1.05rem; line-height: 1.5;">
      <strong>Как это происходит:</strong> Вы случайно ввели пароль на поддельном сайте или поймали скрытый вирус. Мошенник заходит в ваш профиль со своего телефона, но ничего там не меняет, не пишет друзьям и ведет себя абсолютно бесшумно.
    </p>
    <p style="margin-bottom: 0; font-size: 1.05rem; line-height: 1.5; color: var(--vp-c-text-2);">
      <strong>В чем опасность:</strong> Он сидит на вашей странице неделями и спокойно читает личную переписку, сохраняет фотографии из семейных чатов и изучает документы, которые вы когда-либо пересылали. Переписка с близкими, фотографии детей, обсуждение крупных покупок — все это копируется. Позже эти данные используются, чтобы под видом сотрудников банка или госслужб позвонить вам по телефону и развести на деньги, зная о вашей жизни вообще всё.
    </p>
  </div>

  <div style="background: var(--vp-c-bg-alt); padding: 20px; border-radius: 12px; margin-bottom: 35px; border: 1px solid var(--vp-c-divider);">
    <h3 style="margin-top: 0; margin-bottom: 10px; font-size: 1.3rem; font-weight: 700; color: var(--vp-c-text-1);">💻 Ситуация 2: Вход через забытые компьютеры</h3>
    <p style="margin-bottom: 10px; font-size: 1.05rem; line-height: 1.5;">
      <strong>Как это происходит:</strong> Вы вошли в свой ВК с чужого компьютера (например, в гостях, на работе, в МФЦ или в сервисной мастерской, когда сдавали телефон в ремонт) и просто забыли нажать кнопку «Выйти». Либо кто-то угадал ваш старый простой пароль.
    </p>
    <p style="margin-bottom: 0; font-size: 1.05rem; line-height: 1.5; color: var(--vp-c-text-2);">
      <strong>В чем опасность:</strong> Чужой человек получает полный контроль над вашей страницей. В этот же день от вашего имени всем контактам и родственникам улетают сообщения с просьбой срочно занять денег, а вернуть страницу себе становится очень тяжело, так как злоумышленник сразу меняет привязанный номер телефона под себя.
    </p>
  </div>

  <h3 style="margin-top: 0; font-size: 1.4rem; line-height: 1.6; margin-bottom: 15px;">🛡️ Преимущества защиты аккаунта через 2FA:</h3>
  <ul style="list-style: none; padding: 0; font-size: 1.05rem; line-height: 1.6; margin-bottom: 30px;">
    <li style="margin-bottom: 16px; display: flex; gap: 12px; align-items: flex-start;">
      <span style="font-size: 1.3rem; line-height: 1;">🧱</span>
      <span><strong>Защита от массовых взломов.</strong> Большинство страниц взламываются автоматически с помощью специальных программ, которые проверяют базы ранее украденных в интернете паролей. Двойная защита полностью останавливает такие попытки — система запрашивает код подтверждения, которого у программ нет, и доступ блокируется.</span>
    </li>
    <li style="margin-bottom: 16px; display: flex; gap: 12px; align-items: flex-start;">
      <span style="font-size: 1.3rem; line-height: 1;">🎣</span>
      <span><strong>Спасение при вводе пароля на фальшивом сайте.</strong> Если вы случайно перейдете по ссылке из сообщения и введете свой пароль на странице, которая точь-в-точь похожа на ВКонтакте, мошенники все равно не смогут зайти в ваш настоящий профиль, так как у них не будет доступа к вашему телефону для получения СМС-кода.</span>
    </li> 
    <li style="margin-bottom: 16px; display: flex; gap: 12px; align-items: flex-start;">
      <span style="font-size: 1.3rem; line-height: 1;">🚨</span>
      <span><strong>Мгновенное оповещение о чужих попытках входа.</strong> Если кто-то посторонний узнает ваш пароль и попробует войти, вам на телефон сразу придет уведомление или СМС с кодом. Вы сразу поймете, что ваш пароль стал известен посторонним, и сможете спокойно его поменять, пока профиль находится в безопасности.</span>
    </li>
    <li style="margin-bottom: 16px; display: flex; gap: 12px; align-items: flex-start;">
      <span style="font-size: 1.3rem; line-height: 1;">🔒</span>
      <span><strong>Спокойствие за личные переписки и архивы.</strong> Страница в соцсети — это не просто профиль, это ваши личные разговоры, фотографии детей, обсуждение семейных планов или рабочих моментов. Двойная защита гарантирует, что эта информация останется строго конфиденциальной и доступной только вам.</span>
    </li>
  </ul>

    detailsText: 'У вас нет ноутбуков MacBook (MacOS). Программы для смены интернет-адреса (VPN) вы сегодня тоже не включали. Этот вход висит прямо сейчас параллельно с вами.',
    explanation: 'Вход из другой страны на незнакомой операционной системе. Если VPN отключен, это стопроцентный взлом.'
  }
])

const makeDecision = (id, choice) => {
  const device = devices.value.find(d => d.id === id)
  if (device) {
    device.processed = true
    device.decision = choice
  }
}

const isGameOver = computed(() => {
  return devices.value.every(d => d.processed)
})

const allClean = computed(() => {
  if (!isGameOver.value) return false
  return devices.value.every(d => {
    if (d.suspect) return d.decision === 'killed'
    return d.decision === 'safe'
  })
})

const resetGame = () => {
  devices.value.forEach(d => {
    d.processed = false
    d.decision = null
    d.showDetails = false
  })
}

const finishLesson = () => {
  if (typeof window !== 'undefined') {
    localStorage.setItem('lesson_vk_sessions_completed', 'true')
    window.location.href = '/vk-info'
  }
}
